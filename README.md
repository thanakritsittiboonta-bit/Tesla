# EVมานี่มา — Tesla Model Journal & Showroom

Responsive website using only HTML, CSS and vanilla JavaScript. Open `index.html` in a browser; no build step.

## Content
- Showcase: Model 3, Model Y, Model S, Model X, Cybertruck
- Tesla-themed editorial articles, model filter, search, article dialogs and mobile navigation
- All listings are **editorial samples**, not inventory. Newsletter is front-end demo only.
- Independent fan website, **not affiliated with Tesla, Inc.**
